
# QuickNotes

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It allows users to create and organize notes into Personal, Work, and Study categories, search for notes, delete individual notes, and save their notes in browser localStorage so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work, and Study categories.
- Validate empty notes and notes longer than 200 characters.
- Display the creation date and time of each note.
- Delete individual notes.
- Search notes without case sensitivity.
- Display the correct note count.
- Save and load notes using localStorage.
- Clear all notes after confirmation.
- Responsive design for desktop and mobile screens.
- Safe rendering of note text using textContent.

## How to Run Locally

1. Clone or download this repository.
2. Open the `day4` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Add notes and test the available features.

No additional packages or build tools are required.
